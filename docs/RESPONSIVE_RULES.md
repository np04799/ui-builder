# 📱 Responsive Rules – BuilderPro

---

# 🎯 PURPOSE

Define responsive behavior across builder and exports.

---

# 📏 BREAKPOINTS

---

## Desktop

1440px

---

## Tablet / iPad

768px

---

## Mobile

390px

---

# 🧱 RESPONSIVE LAYOUT RULES

---

## Desktop

- Multi-column layouts allowed
- Full spacing system active

---

## Tablet

- Reduce spacing slightly
- Auto-stack complex grids

---

## Mobile

- Single column preferred
- Reduce padding
- Stack all columns

---

# 🧩 COLUMN STACKING

Rules:
- Columns auto-stack vertically
- Prevent overflow
- Maintain readable spacing

---

# 🔠 TYPOGRAPHY SCALING

Desktop → Tablet → Mobile

Must scale:
- Heading sizes
- Padding
- Margins

---

# 🖼 IMAGE RULES

Images must:
- Scale responsively
- Prevent overflow
- Maintain aspect ratio

---

# 🧩 NAVBAR RULES

Mobile:
- Collapse menu
- Use hamburger

---

# 🧩 HERO RULES

Mobile:
- Stack content vertically
- Reduce spacing
- Reduce heading size

---

# 🧩 FORM RULES

Mobile:
- Full width fields
- Consistent spacing

---

# 🚨 INVALID RESPONSIVE BEHAVIOR

DO NOT:
- Allow horizontal scroll
- Overflow content
- Create unreadable text
- Break layout hierarchy

---

# 🧠 RESPONSIVE PREVIEW MODES

Builder must support:
- Desktop preview
- Tablet preview
- Mobile preview

Switching previews must:
- Be instant
- Preserve state
- Preserve layout
